# TinDog (projeto de estudo)

> ⚠️ **Exercício de curso, sem fins comerciais.** Este site é uma recriação
> quase igual ao projeto TinDog, feita para registrar meu progresso.

## Créditos

- **Projeto original:** Dra. Angela Yu / The App Brewery, no curso de
  desenvolvimento web. [Repositório original](https://github.com/appbrewery/tindog)
- **Ideia, textos e fotos:** vieram do curso e não são de minha autoria.
- **Framework e ícones:** [Bootstrap](https://getbootstrap.com) e
  [Bootstrap Icons](https://icons.getbootstrap.com).

TinDog é um app fictício. Depoimentos, preços e publicações citadas são inventados.

Se você for titular de algum conteúdo e quiser a remoção, abra uma issue.

## O que eu mudei em relação ao original

- Uso do Bootstrap 6 (alpha)
- Gradiente azul animado com `@keyframes`
- Botões novos, com textos de humor, e rodapé refeito
- Logos fictícias criadas para o projeto, no lugar das marcas reais
